# Online Radio Platform

A reusable online radio platform built with React, Spring Boot, PostgreSQL, and AzuraCast.

## Project goals

- Broadcast continuous music through AzuraCast AutoDJ.
- Support live programs sent through RadioBOSS.
- Display the current song or program.
- Show the weekly program schedule.
- Allow administrators to manage programs and customize the station's branding.
- Provide a responsive experience on desktop and mobile devices.

## Technology stack

- Frontend: React and TypeScript
- Backend: Java and Spring Boot
- Database: PostgreSQL
- Streaming: AzuraCast
- Live broadcasting: RadioBOSS
- Infrastructure: Ubuntu VPS, Docker, and Nginx

## Project structure

- `frontend/`: Website and administration interface
- `backend/`: REST API and business logic
- `infrastructure/`: Deployment and server configuration
- `docs/`: Architecture and project documentation

## Status

The project is currently in its initial planning and setup phase.
